---
title: "Uninstall"
description: "Remove OpenNCCM from the server."
---

:::caution[Before uninstalling]
Create and download a recovery backup with the key if you want to keep the data.
:::

```bash
sudo opennccm uninstall            # keeps the data and the key
sudo opennccm uninstall --purge    # deletes EVERYTHING, including data and key
```

It asks you to type DESINSTALAR to confirm.
