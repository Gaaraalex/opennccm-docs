---
title: "Glossary"
---

| Term | Meaning |
| --- | --- |
| Running / startup | Configuration in use (active) / saved for the next boot. |
| Version | Copy of the configuration saved when it changes. |
| Baseline | Approved version used as the reference. |
| Configlet | Reusable command template. |
| Change request | Proposal to apply commands that must be approved. |
| Rollback | Returning to an earlier configuration. |
| Maintenance window | Period in which OpenNCCM applies an approved change; its syslog notices are not treated as intrusions. |
| Policy / rule | Set of compliance controls / individual control. |
| device\_type | Platform identifier (Netmiko driver), e.g. `cisco_ios`. |
| CVE / CVSS | Public identifier of a vulnerability / its severity score (0–10). |
| EOL / EOS | End of life / end of sale or support of a model. |
| SCP / MD5 | Secure file copy over SSH / fingerprint to check the file arrived intact. |
| Syslog | Protocol devices use to send their log messages. |
