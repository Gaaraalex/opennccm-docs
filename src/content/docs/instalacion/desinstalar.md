---
title: "Desinstalar"
description: "Quitar OpenNCCM del servidor."
---

:::caution[Antes de desinstalar]
Cree y descargue una copia de recuperación con la clave si quiere conservar los datos.
:::

```bash
sudo opennccm uninstall            # conserva los datos y la clave
sudo opennccm uninstall --purge    # borra TODO, incluidos datos y clave
```

Pide escribir DESINSTALAR para confirmar.
